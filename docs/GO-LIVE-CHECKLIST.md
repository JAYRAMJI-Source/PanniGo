# PaaniGo Go-Live Checklist

1. Supabase project created.
2. `supabase/schema.sql` executed.
3. Render Web Service connected to the repository.
4. Environment variables added in Render.
5. Custom domain connected and HTTPS active.
6. Admin password changed from the example value.
7. Real phone/email/address added to the customer page.
8. Products and delivery zones verified.
9. COD order tested.
10. Online payment tested if enabled.
11. Admin login tested.
12. Order status update tested from a second browser/device.
13. Order tracking tested publicly.
14. Backup/retention settings reviewed.
15. Privacy policy and terms prepared before collecting customer information.
